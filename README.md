眼科に関する過去問を、問題文・全選択肢（原文）、選択肢別の解説、公式正答、出典の順に整理した学習用教材です。

## 教材の入口

|フォルダ|試験|状態|
|---|---|---|
|[l/](l/README.md)|准看護師試験|2020～2026年実施分から51問・選択肢別解説204件を収録した調査版。|
|[r/](r/README.md)|看護師国家試験|第109～115回（2020～2026年実施）の7回・1,680問から眼に関連する87問（直接眼科16・関連領域33・弱い関連38）・選択肢別解説391件を収録|

## 使い方

1. 年度別問題集で問題を解き、公式正答を確認する。
2. 選択肢別の解説で、正答肢と誤答肢の理由を確認する。
3. 出題頻度と参考書で、繰り返し出ている主題を整理する。
4. PDFで印刷して[Gemini Notebook](https://notebook.google/)にアップロードして利用する。

公式正答は試験実施者が公表した正答表に基づきます。解説は独自に作成した学習用原稿で、試験実施者の公式解説ではありません。出典・免責・誤りの連絡先は[この教材について](about.md)を参照してください。
