看護師国家試験の眼科関連問題は準備中です。現時点で公開している問題・解説はありません。

## 予定している構成

准看護師試験（l/）と同じ形式で作成します。

- 問題文・全選択肢（原文）→選択肢別の判定・解説表→公式正答（番号と選択肢本文）
- 出典は厚生労働省が公表する試験問題・正答に基づき、各問に回次・問題番号・公式URLを記載
- 回次ごとの問題集、調査範囲、出題頻度、頻出主題の解説、データ（JSON・CSV）

## 問題IDの予定

`回次＋A/B＋原問題番号（2桁以上）`の形式です。例：`101B06`＝第101回・午後・第6問、`101B100`＝第101回・午後・第100問。

**看護師国家試験のA・Bは午前・午後、准看護師試験のA・Bは日程**を表します。詳細は[問題IDのルール](../l/question-ids.md)を参照してください。
