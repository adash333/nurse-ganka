「少しでも眼科に関連する問題」を収録する方針のため、眼の語が選択肢や事例に含まれるだけの問題（弱い関連）も入れています。分類は各問に明記し、頻度集計では直接眼科だけを数えます。

各問を**問題文・全選択肢（原文）→選択肢別の判定・解説表→公式正答**の形式に統一しています。解説は独自に作成した学習用原稿であり、厚生労働省の公式解説ではありません。

## 分類の基準

- **直接眼科**：眼の構造・機能、眼疾患、眼科の検査・治療・看護、視機能の加齢変化を主に問う問題。
- **関連領域**：主題は他領域だが、眼の症状・所見・疾患名が正答や鑑別の鍵になる問題（例：抗コリン薬と緑内障、Horner症候群、黄疸の眼球結膜）。
- **弱い関連**：眼の語が選択肢・事例文に含まれるが、眼の知識がなくても解ける問題（例：有訴者の「目のかすみ」、PPEのゴーグル、GCSの開眼）。
- 除外：「項目」「目標」「目が覚める」など眼を意味しない語、感情の涙、幻視、見当識障害のみの問題。
