2026年10月16日更新。2020年から2026年の准看護師試験の過去問のうち、取得・確認できた11セット1,650問から、直接眼科28問と関連領域23問、計51問を整理しました。2020～2022年には未確認の地域・日程があります。

51問すべてを、**問題文・全選択肢（原文）→選択肢別の判定・解説表→公式解答（番号と選択肢本文）**の形式に統一しました。選択肢別解説は計204件です。解説は独自に作成した学習用原稿であり、試験実施者の公式解説ではありません。

読み仮名・改行・字間等を整理し、括弧・波ダッシュ等の表記を統一しています。問題文枠の先頭は原問題番号に代えて、`26A23`のような固有IDを表示します。各問に出典PDFのページと正答表へのリンクがあります。「正答・誤答」は設問に対する判定で、誤りを選ぶ問題では誤った記述が正答となります。

## 集計の考え方

年度と実施年を区別します。例：2026年2月の試験は令和7年度。県ごとの転載は重複させず、同じ年・日程の問題を1セットとします。

近年の比較は、A・B両方を調べられた2023～2026年の8セットを主集計とします。2020～2022年の3セットは歴史的補足に分けます。頻出の基準は「直接眼科の主題として、主集計の異なる2年以上に出現」です。全7年分を埋めた後に範囲を再判定する暫定版です。
